# CivicTrack AI

An AI-powered civic issue reporting and resolution platform.

## Project Overview

CivicTrack AI helps citizens report civic issues such as:

- Road damage
- Garbage accumulation
- Water leakage
- Broken streetlights
- Drainage problems

## Technology Stack

- Frontend: React
- Backend: Django REST Framework
- Database: PostgreSQL
- AI: Python and Machine Learning
- Maps: Leaflet and OpenStreetMap

## Project Status

Currently under development.

## Main Objective

To simplify civic issue reporting, improve complaint management, and assist authorities through AI-powered analysis.
